# Android Applications – Kotlin & Android Studio
# kotlin-gmail-login-ui
A collection of simple Android applications developed using **Kotlin and Android Studio**, focusing on beginner-friendly app development, modern XML UI designs, form validation, login screens, and activity navigation.
##  Features
- Simple and modern Android UI designs using XML
- Login and registration screen layouts
- Email and password validation using Kotlin
- Custom Toast messages and error handling
- Activity navigation using Intents
- ImageView and custom logo integration
- Responsive layouts for different mobile screen sizes
- Gradient backgrounds and attractive UI components
##  Technologies Used
- **Language:** Kotlin
- **IDE:** Android Studio
- **UI Design:** XML
- **Platform:** Android SDK
- **Emulator:** Android Virtual Device (Pixel 4)
## 📱 Projects Included
1. Gmail Login UI Design
2. Email and Password Validation
3. Custom Toast Notifications
4. Activity Navigation Using Intents
5. Custom Logo and ImageView Design
6. Responsive XML Layout Designs
##  Project Objective
To develop practical knowledge of Android application development using Kotlin, understand XML-based UI design, implement basic application functionality, and gain hands-on experience with Android Studio.
## ▶️ How to Run
1. Clone or download this repository.
2. Open Android Studio.
3. Select **Open Project** and choose the downloaded project folder.
4. Allow Gradle Sync to complete.
5. Start an Android Emulator or connect an Android device.
6. Click **Run ▶** to launch the application.
